# JARVIS

If you've been asked to install or set up JARVIS on this computer, follow
[INSTALL_WITH_CLAUDE.md](INSTALL_WITH_CLAUDE.md) step by step.

For changes to JARVIS itself: settings live in `.env` (template: `.env.example`),
the assistant's personality is `persona.md`, and the log is
`~/Library/Logs/JARVIS.log`. Never commit `.env` or `tools/.env.local`.
